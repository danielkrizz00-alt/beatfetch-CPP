# BeatFetch (C++)

A live terminal dashboard, ported from the original Python/rich prototype to a compact C++ implementation.


## Requirements

- C++17 compiler and make
- fastfetch, hyfetch, or neofetch
- playerctl
- cava

## Install

```bash
chmod +x install.sh
./install.sh
```

## Run

```bash
beatfetch
```

## Build manually

```bash
make
./beatfetch
```

## Options

```bash
beatfetch --help
```
